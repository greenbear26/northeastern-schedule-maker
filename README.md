# Northeastern Schedule Maker

This is a Python application that helps Northeastern University students create
their class schedules. It allows users to input their desired courses and
generates possible schedules based on course availability and time slots.

## Streamlit UI

This app is hosted on streamlit at this [link](https://neuschedulemaker.streamlit.app/). If the app is not up at first, click the button to wake up the app.
